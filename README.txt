BLACK FRIDAY ELIS ALMEIDA — 2026

COMO EXECUTAR
1. Extraia o ZIP.
2. Abra a pasta black-friday-elis no Visual Studio Code.
3. Instale a extensão Live Server, caso ainda não tenha.
4. Clique com o botão direito em index.html e escolha "Open with Live Server".

ARTES DAS PROMOÇÕES
Coloque suas 18 artes em assets/images/ com estes nomes:
img1.jpg, img2.jpg, ... img18.jpg

As imagens são carregadas com object-fit: contain para preservar a arte completa e sua proporção.
Se seus arquivos forem PNG ou WEBP, altere os caminhos no array PROMOTION_IMAGES em js/script.js.
Não há imagens fictícias incluídas. Enquanto as artes não forem adicionadas, a galeria exibe marcadores de posição numerados.

CONFIGURAÇÃO DO WHATSAPP
Abra js/script.js e altere:
WHATSAPP_NUMBER: "5511999999999"
Use o formato internacional com DDI + DDD + número, somente dígitos.
